# Resume ATS Scanner - Browser Interface

Run:
1. `pip install -r requirements.txt`
2. `python app.py`
3. Open `http://127.0.0.1:5000` in your browser.
4. Upload a PDF/DOCX resume and TXT job description.
5. Click ANALYZE RESUME.
6. Download the CSV report.

The interface includes a formal colored dashboard, keyword results, section checks, formatting checks, and report download.
